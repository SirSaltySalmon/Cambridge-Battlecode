# spar-locker (sparring bot)

`v83-lock` with `LOCK_ANY` on: it buys an altar lock after its core build and puts it on every altar it passes, like the
ladder teams that buy 8-14 locks a game. Use it to check how a change copes with locked altars: v82 vs it 17-17 (gems
+3.6%), v83-lock 19-15 (+7.0%).
