# spar-farmer (sparring bot)

`v82` that ignores enemies (its fight score always says farm) and banks small bags (GEM_BANK 20, Ren 40, near-bank range
10, no escorts). Meant to copy the fast-farming ladder teams on rows, but ignoring enemies makes it far too weak: v82
beats it 33-1. (A first version that always retreated lost 34-0.) Not used for results.
